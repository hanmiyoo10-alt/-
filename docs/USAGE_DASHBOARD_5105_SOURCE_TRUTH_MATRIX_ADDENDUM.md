## Official source semantics

Upstream inspected at `theopenco/llmgateway@db661f93eca2b4a753141cf2ee86cab1b2be248f`.

The official API schema exposes a nullable `nextTier` object including:

- tier target and future rate/cap values;
- `ageDaysRequired`;
- `spendUsdRequired`;
- `daysUntilQualify`;
- `spendUsdUntilQualify`;
- `minAgeDaysRequired`;
- `daysUntilSpendPathUnlocks`.

The shared `getNextSpendTier()` owner states that the next tier is reached by waiting for the age threshold OR meeting the spend threshold once the minimum-age floor is met. It returns null at the top tier and for a pinned tier override.

5.105 deliberately consumes the server-computed remainder fields instead of copying the public trust-tier table into Local Usage Dashboard as a second live authority.

## Isolation and non-inference

The selected Credits org remains part of source identity. A nextTier result for org A must never be displayed for org B. Failure for the selected org remains UNKNOWN and does not authorize fallback.

No progression value may be reconstructed from local spend, account balances, request traffic, or elapsed time.
