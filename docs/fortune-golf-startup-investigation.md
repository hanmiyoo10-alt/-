## 현재 목표
사용자 요청에 따라 컴투스포춘골프3D부터 한 게임씩 진행한다.
다른 세 게임의 개별 APK 작업은 보류한다.
목표는 원본 실행, 전용 터치 조작, 화면 비율을 유지한 확대, 독립 Android 앱이다.
원본 그림의 단순 확대를 HD 리메이크라고 표시하지 않는다.

## 검증된 상태
- 기존 GitHub Actions 34054506111: Android APK 빌드 성공.
- 사용자 휴대폰: 앱 설치 및 게임 로드 후 시작 단계에서 실패.
- 오류: `Unimplemented: 4: stub`.
- 고정 엔진: dlunch/wie @ 1ed8710956e727629e67db762ddc1e6bd6151a1f.
- 해당 엔진의 KTF WIPIC Interface4는 64개 슬롯 모두 미구현 오류를 반환한다.
- 사용자 제공 바이너리의 호출 지점과 오류 레지스터를 대조했다. 반환 지점은 상대 오프셋 0x172e이며, 호출 직전 테이블의 offset 0에서 함수 포인터를 읽는다. 따라서 이번 실패는 Interface4의 슬롯 0 호출로 좁혀진다.
- 호출 인자는 포인터, 128, 0, 1이다. 이것만으로 함수의 의미나 메모리 쓰기 규약을 단정할 수 없다.

## 아직 확인하지 못한 것
Interface4 슬롯 0의 API 이름, 인자 구조, 반환값, 버퍼 소유권 및 수명.
이 함수가 3D 렌더링인지 다른 초기화 기능인지 미확인이다.
타이틀 진입, 홀 플레이, 음악, 저장은 모두 미검증이다.
