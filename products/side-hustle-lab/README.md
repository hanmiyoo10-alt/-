# Side Hustle Lab — 무료 부업 검증소

공개된 부업 아이디어를 복제하거나 수익을 보장하지 않고, 비용·노동·위험·무인성을 같은 기준으로 비교하는 정적 연구 프로토타입이다.

## 먼저 읽기

1. [`CURRENT.md`](CURRENT.md) — 현재 상태와 미확정 항목
2. [`product.json`](product.json) — 이 루트의 선언된 권한과 검증 경로
3. [`data/ideas.json`](data/ideas.json) — 화면에 표시하는 후보 데이터
4. [`src/classifier.mjs`](src/classifier.mjs) — 판정 규칙
5. [`src/feed.mjs`](src/feed.mjs) — 공개 RSS 최소 파서

## 실행

Node.js 20 이상만 필요하며 외부 패키지는 사용하지 않는다.

```bash
cd products/side-hustle-lab
npm test
npm run check
python3 -m http.server 4173
```

그다음 `http://localhost:4173`을 연다.

공개 RSS를 다시 읽어 로컬 검토용 스냅샷을 만들려면 다음 명령을 사용한다.

```bash
npm run sync:rss
```

생성되는 `data/source-feed.json`은 시점 의존 관찰값이라 Git에 커밋하지 않는다.

## 범위

- 부업 후보의 난이도, 간단성, 편의성, 무인성, 위험을 동일한 1~5 척도로 비교한다.
- 비용이나 운영 주체가 확인되지 않으면 `unknown`을 그대로 보존한다.
- 수익 금액은 사용자가 계산기에 직접 입력하며 사이트가 예상 수익을 만들어내지 않는다.
- 제휴 링크, 광고, 결제, 계정 가입, 자동 게시, 외부 앱 설치는 이 프로토타입 범위 밖이다.

## 데이터 흐름

```text
공개 RSS
→ 최소 필드만 정규화한 로컬 관찰값
→ 사람이 확인한 후보 데이터
→ 결정론적 분류기
→ 정적 비교 화면과 시간 계산기
```

RSS 제목은 후보 발견용일 뿐 방법·수익·안전을 증명하지 않는다. `data/ideas.json`에 후보를 추가할 때는 원문 링크와 evidence 상태를 함께 기록한다.

## 보안·준법 경계

- 토큰, 쿠키, 계정 정보, 정산 정보, 개인 식별 정보를 저장하지 않는다.
- 차단된 페이지를 우회하거나 인증이 필요한 콘텐츠를 수집하지 않는다.
- 타인의 글·영상·이미지를 복제하지 않는다.
- 제휴 또는 AI 생성물을 실제로 게시할 때는 해당 플랫폼의 최신 공식 고지·권리 규칙을 별도로 확인한다.
- `recommended`는 비교 규칙상 우선 검토 대상이라는 뜻이며 수익 보장이나 법률·세무 판단이 아니다.

## 검증

```bash
npm test
npm run check
```

- RSS 파서가 공개 항목의 최소 필드만 추출하는지 확인한다.
- 불완전한 근거, 무료 체험, 유료, 고위험 후보가 자동 추천되지 않는지 확인한다.
- 데이터가 임의의 수익 수치를 포함하지 않는지 확인한다.
- 정적 사이트의 필수 파일과 고지 문구가 존재하는지 확인한다.
