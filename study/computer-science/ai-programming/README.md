## Study method

초기 기본 루프는 다음처럼 둡니다.

```text
개념 1개 확인
→ 짧은 코드 직접 작성
→ 실행 전 결과 예측
→ Colab에서 실행
→ 결과가 다르면 원인을 가장 좁은 범주로 분류
→ 비슷한 예제로 다시 확인
```

오류/혼동은 가능하면 다음처럼 구분합니다.

```text
SYNTAX
TYPE
INPUT_CONVERSION
OPERATOR
VARIABLE_STATE
OUTPUT_FORMAT
CONCEPT
```

이 분류가 실제 학습에 도움이 되는지는 문제/실습 증거가 쌓인 뒤 판단합니다.
