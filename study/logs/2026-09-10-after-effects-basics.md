# 2026-09-10 After Effects 기초 학습 기록

## 학습 맥락

중간고사 과제로 약 50초~1분 10초 분량의 가로형 타이포그래피 기반 모션그래픽 영상을 제작해야 한다.

과제 요구사항으로 확인한 내용:

- 자유 주제
- 텍스트 모션이 영상의 메인
- 음악/음성 자유 활용 가능
- 기존 MV를 배경으로 쓸 경우 텍스트/문자가 없는 장면만 사용
- 작품 설명 A4 1장 PDF 제출
- 작품 설명에는 작품 설명, 사용한 주요 모션, 키프레임이 보이는 작업 파일 스크린샷, 영상 URL 포함
- 영상 열람 권한 확인 필요

현재 주제 후보는 **“집 가고 싶다”**이다. 아직 최종 확정으로 보지 않는다.

## 환경 설정

After Effects가 한글 UI로 설치되어 있어 영어 UI로 전환했다.

Windows 문서 폴더에 다음 빈 파일을 만들어 After Effects를 영어 UI로 실행하도록 설정했다.

```text
ae_force_english.txt
```

문서 폴더가 바로 보이지 않아 `Win + R`에서 `shell:Personal`을 사용해 실제 Documents 경로를 열었다.

## 오늘 익힌 After Effects 기본기

### 1. Composition 생성

연습용 컴포지션을 만들고 Shape Layer로 사각형 오브젝트를 생성했다.

기본 연습 설정:

```text
1920 x 1080
30 fps
약 5초
```

### 2. Position 키프레임

- Shape Layer 선택
- `P`로 Position 표시
- 0초에서 Position 스톱워치 활성화
- 2초 지점에서 오브젝트 위치 변경
- 두 위치 사이가 자동 보간되어 이동하는 것을 확인

### 3. Easy Ease

두 Position 키프레임을 모두 선택한 뒤 `F9`를 눌러 Easy Ease를 적용했다.

일정 속도 이동과 달리 시작/종료 구간의 움직임이 부드러워지는 것을 직접 확인했다.

### 4. Graph Editor / Speed Graph

- Graph Editor 진입
- 처음에는 빨간색/초록색 선이 보이는 Value Graph 상태를 확인
- `Edit Speed Graph`로 전환
- 밝은 단일 속도 그래프와 키프레임 핸들을 이용해 가속/감속을 변경
- 그래프 모양에 따라 같은 이동 시간 안에서도 체감 속도가 달라지는 것을 확인

### 5. Scale 키프레임

`S`로 Scale을 열고 다음 값으로 연습했다.

```text
0초: 50%
1초: 150%
2초: 100%
```

세 키프레임에 Easy Ease를 적용해 작게 시작한 오브젝트가 커졌다가 원래 크기로 돌아오는 모션을 만들었다.

### 6. Opacity 키프레임

`T`로 Opacity를 열고 다음 값으로 연습했다.

```text
0초: 0%
1초: 100%
2초: 0%
```

오브젝트가 나타났다 사라지는 페이드 모션을 만들고 Easy Ease를 적용했다.

## 오징어게임 레퍼런스 확보

Google Drive의 정리 경로에서 실제 레퍼런스 파일을 확인했다.

```text
학교_전공공부
→ 01_과목자료
→ 영상편집실습
```

해당 폴더 안에 다음 파일이 있다.

```text
Squid Game - Intro motion logo - English version (1080p).mp4
Squid Game - Intro motion logo - English version (1080p).mp3
오징어게임 로고 (Squid Game LOGO) (1080p).mp3
오징어게임.png
[영상편집실습]1주차-목요일.pdf
```

오늘 따라 만들 기준 영상은 `Squid Game - Intro motion logo - English version (1080p).mp4`로 확인했다.

기술 정보:

```text
1920 x 1080
30 fps
약 18.09초
H.264 video + AAC audio
```

1초 간격으로 전체 흐름을 확인한 결과, 검은 배경 위에 기하학적 선/도형이 조립되고 한글 로고 형태가 완성된 뒤 분해되며, 이어 영어 `SQUID GAME` 로고가 조립되어 완성되고 마지막에 페이드 아웃되는 구조다.

## 수업 녹음 / 자동 전사 확인

같은 `영상편집실습` 폴더에 2026-09-10 수업 녹음과 자동 전사 파일이 함께 있다.

```text
음성 260910_091822.m4a
음성 260910_091822_original.txt
```

전사 파일은 UTF-16 텍스트이며 자동 음성인식 오탈자가 적지 않다. 따라서 문장 자체를 정확한 강의록으로 취급하기보다, 타임코드와 작업 순서를 복원하는 보조 근거로 사용한다.

현재 확인된 수업 흐름 중 AE 실습과 직접 관련된 부분:

```text
약 01:04  오징어게임 자료 다운로드 안내
약 04:36  개인 노트북 사용자는 영어 버전 권장
약 06:07  After Effects 작업창을 Composition이라고 설명
약 07:08  새 Composition에서 Duration 설정 강조
약 09:29  기본 도형부터 연습한 뒤 오징어게임 로고 형태로 확장 예정
약 11:32  Shape Layer 생성 확인
약 12:39  Fill을 없애고 Stroke 중심으로 도형 설정
약 14:18  Align으로 가운데 정렬
약 15:15  Anchor Point 개념과 중앙 배치 설명
약 16:31  기초 모션으로 Position / Scale / Rotation / Opacity 설명
약 18:17  Position 키프레임 실습 시작
약 21:41  최소 두 키프레임 사이에서 움직임이 발생한다고 설명
약 22:23  키프레임 간격으로 속도를 조절하는 원리 설명
```

이후 오징어게임 레퍼런스를 따라 만들 때, 영상만 보고 추정하기 어려운 단계는 이 전사의 타임코드를 보조 기준으로 다시 확인한다.
