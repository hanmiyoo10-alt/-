## 1회차 1과목 하 변형문장 퀴즈 진행

- 손필기 `?` 보충과 기본 개념 검수 후, 2025년 8월 1회차 1과목 하 난이도 범위를 대상으로 변형문장 퀴즈를 여러 묶음 진행함.
- 출제량은 첫 10문제 + 추가 5문제씩 4회로 총 30문제.
- 직접 정의형뿐 아니라 같은 개념의 변형 표현, 유사개념 구분, O/X, 복수선택을 섞어 키워드 판별이 문장 변화에도 유지되는지 확인하는 구성으로 진행함.
- 다룬 주요 범위: Class/Method/Message/Inheritance, GoF Composite/Adapter/Decorator/Observer, Pipe-Filter, Agile/Prototyping, XP 가치와 Pair Programming, Cohesion/Coupling, State/Event/Transition, NUI 제스처, Activity Diagram/Flow, 데이터 오류 유형, SOLID, FEP, Top-Down/Bottom-Up Design, 소프트웨어 공학 기본 방향.
- 현재 대화 표면에는 각 문항별 실제 선택 결과나 정답률이 노출되지 않아 `O/△/X` 및 오답 원인은 아직 확정 기록하지 않음.
- 같은 하 난이도 범위의 신규 퀴즈를 계속 늘리는 것보다, 이후에는 실제 오답/버벅임이 있었던 개념만 선택 재검증하는 편이 효율적이라고 판단함.

## 퀴즈 결과 추적 방식 보완

- 퀴즈 UI의 실제 선택 결과를 AI가 직접 확인하지 못하는 경우가 있으므로, 앞으로 사용자가 오답 또는 버벅인 문항을 별도로 체크해 전달하기로 함.
- 사용자가 체크한 결과만 근거로 `O/△/X`와 오답 원인을 확정하며, 확인되지 않은 결과를 추정해서 기록하지 않는다.
- 하 난이도는 `즉답=O`, `맞았지만 느리거나 확신 부족=△`, `오답=X` 기준으로 재검증 대상을 고른다.
