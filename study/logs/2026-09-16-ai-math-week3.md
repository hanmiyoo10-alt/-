## 3주차 실제 내용 맵

### `AI입문3-1.mp4` (~18분)

프레임 확인 기준 강의노트 `2.1 도함수`를 다룬다.

- 할선의 기울기에서 극한을 취해 접선의 기울기/미분계수를 정의
- `f'(a) = lim_{h->0} (f(a+h)-f(a))/h`
- `f'(x)`를 함수로 보는 도함수 개념
- 상수함수의 도함수는 0
- 미분가능의 의미와 미분 불가능한 대표 상황
  - 불연속
  - 첨점/뾰족점
  - 수직 접선
- 거듭제곱형 함수 예제
- 지수함수의 도함수 `e^x`, `a^x`
- 접선 기울기를 이용한 예제: `y=e^x`에서 기울기 2인 접점
- 삼각함수 도함수 `sin`, `cos`, `tan`, `sec`, `csc`, `cot`

### `AI입문3-2.mp4` (~28분)

프레임 확인 기준 강의노트 `2.2 미분 법칙`이 중심이며 끝부분에서 `2.3 증가함수와 감소함수` 진입까지 확인된다.

- 합/상수배/곱/몫의 미분법
- 곱의 미분법을 이용한 수치형 예제
- 몫의 미분법 예제 `sec x / (1+tan x)`
- 합성함수와 Chain rule
  - `(g∘f)'(x) = g'(f(x)) f'(x)`
- 여러 층의 합성함수 미분 예제
- 음함수 `F(x,y)=0`와 음함수 미분
  - `y`를 `x`의 함수로 보고 양변을 `x`에 대해 미분한 뒤 `dy/dx`로 정리
- 원 `x^2+y^2=25`의 접선 기울기 예제
- 로그함수의 도함수
  - `(ln x)' = 1/x`
  - 일반 로그 도함수
  - `ln|x|`의 도함수
- 영상 후반에 `2.3 증가함수와 감소함수` 제목 진입

1. 도함수 정의, 접선 기울기, 합/곱/몫/연쇄법칙을 한 장에 요약한 필기

## 이번 주 개념 구조

```text
평균변화율/할선
→ 극한
→ 순간변화율 = 도함수 = 접선의 기울기
→ 기본 함수 도함수
→ 합/곱/몫의 미분법
→ 합성함수와 연쇄법칙
→ 음함수 미분
→ 접선/기울기/절편 문제 적용
→ 다음 절: 증가·감소 판정
```

핵심은 공식을 각각 외우는 것보다 `현재 함수가 어떤 구조인가`를 먼저 구분해서 적절한 미분법을 선택하는 것이다.
