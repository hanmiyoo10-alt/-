## 4주차 실제 내용 맵

### `AI입문4-1.mp4` (~28분 49초)

대표 프레임과 강의노트를 교차확인한 결과 `2.3 증가함수와 감소함수`가 중심이다.

- 도함수 부호로 증가·감소 구간 판정
  - `f'(x) > 0`이면 증가
  - `f'(x) < 0`이면 감소
- 도함수의 영점을 기준으로 구간을 나누고 부호표 작성
- 극댓값·극솟값의 의미
- 1계도함수 판정법
  - `+ → -`: 극대
  - `- → +`: 극소
  - 부호 변화 없음: 극값 아님
- 다항함수의 증감 구간 예제
- `x + 2 sin x` 형태의 삼각함수 예제에서 임계 후보와 극값 판정

### `AI입문4-2.mp4` (~22분 32초)

대표 프레임과 강의노트를 교차확인한 결과 `2.4 최댓값과 최솟값`이 중심이다.

- 최댓값·최솟값의 정의와 극댓값·극솟값과의 구분
- 닫힌 구간의 연속함수에 대한 최댓값·최솟값 존재 정리
- 미분 불가능한 점도 최댓값·최솟값 후보가 될 수 있음
- 정점, 특이점, 임계점
  - `f'(c)=0`인 정점
  - 도함수가 존재하지 않는 특이점
  - 둘을 합친 임계점
- 최댓값·최솟값 후보는 임계점 또는 끝점
- 닫힌 구간에서
  `내부 임계점의 함숫값 + 양 끝점의 함숫값`
  을 모두 비교하는 절차
- 도함수 부호 변화를 이용한 전구간 최댓값·최솟값 판정
- `x ln x` 형태의 예제

## 4주차 연습문제 구조

`4주차 연습문제 풀이...` PDF에서 확인되는 문제 범위는 4.1~4.7이다.

- 4.1: 정의역을 고려한 감소 구간 판정
- 4.2: 포물선과 직사각형 넓이 최적화
- 4.3: 두 곡선 사이에 내접한 직사각형 넓이 최적화
- 4.4: `x^(1/x)`의 로그미분과 전구간 최댓값 판정
- 4.5: 직사각형 종이로 만드는 열린 상자의 부피 최적화
- 4.6: 도함수 부호 변화로 극댓값을 판정하고 매개변수 결정
- 4.7: 닫힌 구간에서 임계점과 끝점의 함숫값 비교

연습문제의 핵심은 미분 계산 자체보다
`함수 모델 만들기 → 정의역/구간 확인 → 임계점 찾기 → 도함수 부호 또는 후보값 비교 → 최적값 해석`
의 연결이다.

## 이번 주 개념 구조

```text
f'(x)의 부호
→ 증가 / 감소
→ 증감이 바뀌는 지점
→ 극대 / 극소
→ 임계점
→ 닫힌 구간에서는 끝점도 후보
→ 후보 함숫값 비교
→ 최댓값 / 최솟값
→ 넓이·부피 등의 최적화 문제
```

AI와의 연결에서는 손실함수의 값을 작게 만드는 학습 문제를 이해하기 위한 1변수 미분·최적화의 기초 구간으로 볼 수 있다.

## 공부 진행 증거 — 4.4 로그미분

- 사용자가 `학교_전공공부/01_과목자료`에 가장 최근 파일로 `Notes_260923_160036.sdocx`를 업로드했다.
- 이 파일은 Samsung Notes `.sdocx` 형식의 손필기 노트이며, 필기 스트로크를 직접 렌더링하여 내용을 확인했다.
- 현재 4.4 문제 `f(x)=x^(1/x)` 풀이에서 `(ln x)/x = x^(-1) ln x`로 바꾼 뒤
  `-x^(-2) ln x + 1/x^2`
  로 미분한 흔적이 확인된다.
- 이는 `(1-ln x)/x^2`와 동치이므로 해당 미분 단계는 맞다.
- 이 한 단계의 정답을 장기 학습 특성이나 일반적인 강점으로 승격하지 않는다.
- 새 노트는 `AI 수학 입문/4주차` 폴더 안이 아니라 `01_과목자료` 루트에 있으므로, 이후 최신 필기 확인 시 주차 폴더만 조회하면 놓칠 수 있다.
