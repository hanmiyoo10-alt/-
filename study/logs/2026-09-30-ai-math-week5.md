## 5주차 실제 내용 맵

### `음성 260930_111853.m4a` (~72분 37초)

- AAC, 48 kHz, mono의 수업 전체 녹음이다.
- 전체 시간축을 가로지르도록 0/12/24/36/48/60/70분 지점에서 각 2분씩 총 7개 구간을 로컬 음성인식으로 확인했다.
- 자동전사 오자가 있어 축어록으로 사용하지 않고, 영상·필기·PDF와 교차해 강의 흐름/강조점을 확인하는 보조 근거로 사용한다.

확인된 시간축 내용:

- 0분대: 벡터는 위치를 평행이동해도 크기와 방향이 같으면 같은 벡터이며, 순서쌍으로 표현되는 위치벡터는 원점에서 출발한다는 점을 반복 강조한다. 일반 유향선분은 시점→종점으로 표현한다.
- 12분대: 벡터 덧셈과 스칼라배만으로는 일반적인 두 벡터 사이의 각을 표현하기 부족하다는 동기에서 추가 연산, 특히 내적을 도입한다.
- 24분대: 내적으로 `cos θ`를 계산하고 일반적인 각 `θ`는 역코사인으로 구하는 설명이 확인된다.
- 36분대: 벡터적(cross product)의 정의와 성분 공식을 도입하며, 공식이 복잡하므로 익숙해져야 한다는 식의 설명이 나온다.
- 48분대: 연습문제 풀이로 넘어가 평행 벡터의 스칼라배 조건과 두 점 A,B에서 `AB = B-A`로 위치벡터를 구하는 설명이 확인된다.
- 60분대: 세 점 P,Q,R이 만드는 평면에서 `PQ`, `PR`을 구하고 두 벡터의 벡터적으로 평면에 수직인 법선벡터를 만드는 논리를 설명한다.
- 70분대: 후반 정리/증명 및 방향·평행·법선과 관련된 설명이 이어진다. 자동전사 품질이 낮아 이 구간의 세부 문장을 독립 사실로 확정하지 않는다.

표본 구간에서는 별도의 중간고사 범위 공지나 명시적인 시험 출제 예고를 확정할 만한 문장은 확인되지 않았다. 이는 72분 전체 축어 전사가 아니라 시간축 표본 확인 결과이므로, 녹음 어딘가에 그런 언급이 전혀 없었다는 뜻은 아니다.

### `AI입문5-2.mp4` (~25분 13초)

영상 전 구간의 화면을 구간별로 확인한 기준으로 내적과 벡터적이 중심이다.

- `3.2 내적`
- 유클리드 노름과 단위벡터
- 내적의 대칭성/선형성/양의 정부호 성질
- 내적을 이용한 두 벡터의 각
- 직교 조건 `u·v = 0`
- 정규직교 기저 개념
- 벡터의 정사영과 정사영 공식
- 벡터적(cross product)의 정의와 성분 계산
- `i×j=k` 등 표준기저의 벡터적
- 영상 후반에 `3.3 직선의 방정식`으로 진입

현재 환경에는 강의 음성의 정밀 전사 경로가 없어, 영상의 교수자 발화 전체를 축어 단위로 검증했다고 간주하지 않는다. 강의 범위는 영상 화면 전 구간의 구간별 프레임 확인으로 매핑했다.

### `5주차 연습문제 풀이260925.pdf`

PDF 원본을 렌더링해 2페이지 전체를 육안 확인했다. 문제 범위는 5.1~5.8이다.

- 5.1 평행한 벡터와 스칼라배
- 5.2 두 점에서 위치벡터 구하기
- 5.3 내적을 이용해 두 벡터 사이의 각 구하기
- 5.4 두 벡터에 모두 수직인 단위벡터
- 5.5 벡터적 계산
- 5.6 세 점이 만드는 평면의 법선벡터와 평행 조건
- 5.7 양방향 벡터 정사영과 정사영 사이의 각
- 5.8 단위벡터 `u, v`에 대해 `u+v`와 `u-v`가 수직임을 내적으로 증명

연습문제는 영상의 흐름인 `벡터 연산 → 내적/직교 → 정사영 → 벡터적/평면 법선`을 직접 적용하게 구성되어 있다.

### `Notes_260930_122601.sdocx`

파일 원본의 SDOCX 바이너리를 직접 해석해 S-Pen stroke event 좌표를 복원하고 페이지 이미지로 렌더링했다. 원본 포맷의 페이지 종료 마커와 스트로크 구조까지 일관되게 파싱되었다.

- 총 9페이지
- 필기 존재 페이지: 8페이지
- 마지막 9페이지: 빈 페이지
- 복원된 S-Pen 획: 1,391개
- 복원된 stroke point: 104,419개
- 모든 비어 있지 않은 페이지를 1200×1697 좌표계에서 렌더링하여 육안 확인

필기 내용은 강의 영상/PDF와 일치하며 다음 흐름을 직접 적어 둔 수업 필기다.

1. 벡터의 방향, 위치벡터, 스칼라와 벡터, 점 P/Q/R 사이의 유향선분
2. 벡터의 크기와 노름, 단위벡터, 평행/반대방향 관계
3. 내적과 두 벡터 사이의 각, `cos θ = (u·v)/(||u||||v||)`, 직교 조건
4. `v⊥w ⇔ v·w=0`, 평행 벡터, 벡터적 성분 공식과 `v×w = -(w×v)`
5. `||v×w|| = ||v||||w|| sin θ`와 벡터적의 기하적 의미
6. 연습문제 5.1~5.2 풀이 흔적: 평행 조건의 스칼라배, 두 점의 위치벡터
7. 연습문제 5.4와 5.6 풀이 흔적: 두 벡터에 수직인 단위벡터, 평면의 법선벡터
8. 연습문제 5.8 풀이 흔적: 단위벡터 `u,v`에 대해 `(u+v)·(u-v)=||u||²-||v||²=0`

따라서 이전의 `RENDER_LIMITATION`은 해소되었다.

## 이번 주 개념 구조

```text
벡터와 좌표
→ 벡터 덧셈 / 스칼라배 / 평행
→ 벡터의 크기와 단위벡터
→ 내적
→ 각도와 직교
→ 정사영
→ 벡터적
→ 평면의 법선벡터
→ 다음 절: 직선의 방정식
```

## 오늘 권장 진행 순서

1. 위치벡터·벡터 덧셈·스칼라배·평행 조건을 먼저 확인한다.
2. 내적과 벡터의 크기에서 각도/직교 공식이 어떻게 나오는지 연결한다.
3. 정사영 공식에서 분모가 `v·v = ||v||^2`인 이유를 이해한다.
4. 벡터적의 방향과 평면 법선벡터 관계를 확인한다.
5. 5.1~5.8을 풀이를 가리고 직접 푼다.
6. 틀린 경우 `개념 조건 해석 / 공식 선택 / 성분 계산 / 부호·대수 계산 / 기하적 의미 연결`을 분리한다.
7. 실제 오답이 생기면 문제 단위 증거를 `study/problems/LEDGER.md`에 남긴다.
