## 과목별 다음 행동

### AI 중심세상
1. 2주차부터 실제 학습 시작
2. 2~4주차를 순서대로 1회독
3. 시험범위 공지 확인 후 범위 밖 내용 분리
4. 각 주차 핵심 개념을 질문형으로 변환

### AI 프로그래밍입문
1. 3주차까지 현재 이해 상태 다시 확인
2. 이후 주차 자료가 있다면 최신 수업 진도와 간격 확인
3. 문자열 리터럴/이스케이프 조합은 짧은 전이 문제로 재검증
4. 시험형 코드 예측/오류 찾기 문제로 전환

### 커뮤니케이션이론
1. 현재 1회차 정리본 기준으로 미정리 주차 확인
2. 1회독 완결
3. 이론명 ↔ 핵심 주장 ↔ 대표 학자/개념 연결 암기
4. 이후 백지복습 또는 단답형 테스트

### 디자인과 시각문화
1. 현재 1회차 정리본이 커버한 범위 확인
2. 미정리 주차를 이어서 1회독
3. 개념/작품/시각문화 사례 연결
4. 비교형 문제 대비

### 미디어 리터러시
현재 정리 확인 범위:
- 정보·정보사회
- 미디어/리터러시
- 미디어 리터러시와 소셜미디어 리터러시
- 미디어 교육
- 프레이밍
- 정보주체 권리
- 매스커뮤니케이션
- 저널리즘/뉴스
- 공론장/시민저널리즘
- 데이터·온라인·AI 저널리즘
- 뉴스룸, 뉴스 선별, 객관성·공정성

다음은 새로운 정리보다 회상 연습과 문제화 비중을 높인다.
