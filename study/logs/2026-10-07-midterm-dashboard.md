## 1회독 진행 형식

시험공부 폴더의 기존 1회독 정리 파일 형식을 기준으로 다음 마이크로 사이클을 사용한다.

```text
PPT/PDF에서 작은 개념 하나 선택
→ 개념 이해/설명
→ 사용자가 화살표·괄호·핵심어 중심으로 자기식 압축 정리
→ 방금 배운 범위의 짧은 확인문제 2~3개 안팎
→ 사용자 답변
→ 즉시 확인/교정
→ 다음 개념
```

확인문제는 핵심어 회상, O/X·판별, 개념 간 차이/관계 확인 중심이다. 1회독 중에는 전체범위 시험형 모의고사를 사용하지 않는다. 전체범위 시험형 문제는 1회독 완료 후 반복 단계에서 시작한다.

## 1회독 이후 공통 반복 프로토콜

영상편집실습을 제외한 모든 과목은 1회독 완료 후 아래 루프로 전환한다.

```text
시험범위 1회독 완료 (PPT/PDF 중심)
→ PPT/PDF + 강의 녹음 + 영상 기준으로 실제 시험 형식 분석
→ 해당 과목의 시험범위 전체를 포함한 새 누적 모의고사 문제 파일 생성
→ 사용자가 답/풀이를 전부 작성
→ 채점 및 오답·불확실 영역 분류
→ 별도 해설지 파일로 정답 근거와 개념 복구
→ 해설지 학습
→ 오답 영역을 다음 회차 출제 가중치에 반영
→ 새 모의고사 생성
→ 반복
```

운영 규칙:

- 문제지와 해설지는 분리한다.
- 사용자가 문제를 다 풀기 전에는 정답과 해설을 노출하지 않는다.
- 1회독의 기본 학습 소스는 PPT/PDF다.
- 2회독 이후 모의고사 출제 근거는 PPT/PDF + 강의 녹음 + 영상이다.
- 실제 시험 형식, 문항 유형, 배점/문항 수 정보가 확인되면 모의고사도 그 형식을 우선 모사한다.
- 모든 회차는 해당 과목의 중간고사 전체 시험범위를 빠짐없이 포함한다.
- 다음 회차도 전체 범위 누적 출제를 유지하며 새 문항으로 구성한다. 이전 오답과 불확실 영역은 문항 수·변형·난이도·재검증 강도만 높이고, 다른 범위를 생략하는 근거로 사용하지 않는다.
- 특정 문제를 외워 맞힌 것을 학습 완료로 보지 않고 새 문항에서 전이 여부를 확인한다.
- 이 반복은 중간고사 종료 또는 사용자의 전략 변경 전까지 회차 제한 없이 계속한다.
