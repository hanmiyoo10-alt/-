# 2025년 8월 1회차 난이도 분류

학습 목표: 이론형/실기연계형을 가리지 않고 `하·중` 난이도까지 전부 맞히기.

판정 기준:
- 하: 한 개념을 알고 있으면 바로 답하거나 한 단계 적용으로 끝나는 문제
- 중: 여러 개념 비교, 2단계 이상 적용, 실제 계산/추적이 필요한 문제
- 상: 여러 개념을 결합한 복합 응용형

교재 자체 A/B/C/D 표시는 출제 빈도 등급이며 아래 학습 난이도와 별개다.

## 1과목 소프트웨어 설계 1~20
- 하: 1, 2, 3, 4, 6, 7, 8, 9, 11, 12, 14, 17, 18, 19, 20
- 중: 5, 10, 13, 15, 16
- 상: 없음

## 2과목 소프트웨어 개발 21~40
- 하: 22, 25, 26, 27, 28, 29, 33, 34, 35, 36, 38, 39, 40
- 중: 21, 23, 24, 30, 31, 32, 37
- 상: 없음

## 3과목 데이터베이스 구축 41~60

### 하 난이도
- 41: DAS 연결 프로토콜 기본 구분. iSCSI는 네트워크 기반이므로 DAS와 구별.
- 44: 정규화의 핵심이 릴레이션 합병이 아니라 분해라는 기본 개념.
- 45: 범위/해시/조합/목록/라운드로빈 등 파티션 유형의 기본 회상.
- 48: 자료 사전은 DBMS가 생성·유지하며 일반 사용자가 직접 갱신하지 않는다는 기본 개념.
- 49: DML과 DDL 구분. ALTER는 DDL.
- 52: 분산 데이터베이스의 분산 투명성 기본 개념.
- 53: ACID 중 일관성(Consistency) 정의.
- 55: 1:N 관계의 기본 판별.
- 56: 데이터 모델 구성 요소 중 연산(Operation)의 정의.
- 57: 도메인(Domain)의 정의.
- 58: `GRANT UPDATE ON STUDENT TO PARK` 기본 권한 부여 구문.

### 중 난이도
- 42: `ON DELETE NO ACTION / CASCADE / SET NULL / SET DEFAULT`를 서로 구별해야 하는 참조 무결성 옵션 문제.
- 43: 관계대수 수학 표현식을 읽고 카티션 프로덕트를 판별.
- 46: 뷰의 여러 특성을 동시에 판별.
- 47: 릴레이션의 여러 특성을 동시에 판별.
- 50: 관계대수 집합 연산별 카디널리티 성질을 적용해 교집합 판별.
- 51: 외래키의 NULL, 중복, 기본키 일부 가능 여부, 참조 무결성 등 여러 성질을 동시에 판별.
- 54: 중첩 SELECT/서브쿼리를 순서대로 실행해 결과를 구하는 SQL 실행형.
- 59: `DROP VIEW ... RESTRICT`와 뷰 의존 관계를 함께 적용.
- 60: 인덱스의 검색 성능, B-Tree, 범위 검색, 생성·변경 가능 여부 등 여러 특징을 동시에 판별.
