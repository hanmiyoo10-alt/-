# Placeholder examples

The following values are intentionally fake documentation placeholders:

```text
API_TOKEN=<redacted>
PASSWORD=example-placeholder
SESSION_TOKEN=not-a-real-token
```

Never replace them with live credentials. The skill only checks that examples are visibly
redacted before documentation is published.
